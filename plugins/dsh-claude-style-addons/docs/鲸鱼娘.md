`manifest.json` 保存全部 18 个原版状态名。待机、张望、悬挂与爬回、睡觉、醒来、思考、打字已接好。其余 11 个状态保持 `pending`，与未知状态一样回退到会动的待机。占位只是动作配置，不会额外显示占位图案。

## 后续增加动作

1. 制作新的透明 PNG 图集，每个关键姿势占一格 128 × 128；头、手、尾巴和鞋子都留安全边距。
2. 在 `manifest.json` 的 `sheets` 中登记文件名、帧数，在 `clips` 中登记持续时间、是否循环和 `poses`。
3. 每个姿势给出出现时间 `at`、图集 `sheet`、帧号 `frame` 和支点 `anchor`。坐姿支点是臀部/手掌的接触高度，悬挂姿势是抓住上沿的手；`targetX` 决定支点在人物容器里的横向位置。
4. 把对应 `states` 条目的 `status` 改成 `ready`，`clip` 指向新动作。其他条目可继续占位，不必一次补齐。
5. 执行 `node tools/build-maid.mjs`（改过 `idle.png` 或 `look-v2.png` 后先加 `--derive` 重新派生眨眼与张望头、清理游离像素；`--drawn-assets` 会自动派生），把配置、渲染代码和 PNG 字节嵌入 `client.js`。重新切分新版连续动作时用 `--drawn-assets`；只整理素材而暂不更新插件时加 `--pack-only`。旧参数 `--assets` 会重建最初三张图集，不要用于本轮更新，以免动到已经批准的待机素材。

正面打字素材用 `--typing-assets`，只构建独立预览用 `--preview-only`（输出 `preview/maid-bundle.js`，不改实际插件）。思考原图见 `source/think.png` 与 `expressions-layout.json`。

`contacts` 可登记手掌/臀部在图格里的接触点，用于小范围接触阴影。`rear` 是处在输入框后面的尾巴或发梢矩形 `[x,y,width,height]`：只遮掉矩形中低于输入框上沿的部分，腿和手仍在前景。每张姿势可分别配置，不必整个人一起裁切。

`part: "head"` 表示只取该帧的头部（第 0–77 行），身体使用原待机图与运动；这类图集必须由 `--derive` 从待机第 0 帧派生，保证头部以外与待机图逐像素一致，否则会出现接缝。旧字段 `transition`、`rigs`、`sway` 已不再使用（斜切摆动在像素图上会撕出横纹）。素材整理在同一图组内保持共同缩放比例，不把蜷缩的身体自动放大；手部接触点保存在 `source/contact-points.json`，换图或重新调整裁切后需重新标定。

## 挂载与恢复

可编辑渲染源文件是 `mascot/runtime.js`，不要直接改 `client.js` 的自动生成区。插件观察原版 Deepy 的动作状态，所以仍跟随原版的工作、闲置与交互时机。首页与对话页都读取实际输入框上沿，人物显示在输入框前方，尾巴由局部遮挡形成前后关系。

素材成功加载并画出第一帧后，才隐藏原版精灵。切回原版、关闭插件、切换品牌或卸载时会移除鲸鱼娘画布、样式和监听器，显露原版。没有修改原版的 PNG、状态机或动画表。

呼吸只把头部整像素抬起 1 个屏幕像素，人物原点也对齐到屏幕像素网格，避免像素图因小数位移逐帧重新取样而闪烁。

转身姿势的支点不再都取手掌：坐着转身时取臀部落在边缘上，转到背面后几帧逐步把人放低，接上抓边下降；爬回时对称地逐步升回坐姿。正面、侧面的转身帧带 `rear`，尾巴和后发留在输入框后面。

关闭动态效果时保持静态；页面不可见时停止动画；输入或点击时中止闲置动作；下方空间不足或可能盖住发送按钮时不悬挂。未来补充悬挂动作仍需维持手部支点，避免靠整张图片平移制造动作。

## 0.5.0 表情层与道具层

- **表情层**：`face.png` 由 `--derive` 生成。第 0 帧是程序画的睡眼；之后各帧来自 GPT 画的 `source/expressions.png`（布局 `source/expressions-layout.json`）。程序先把 GPT 画的人对齐到待机头，再只取待机图里属于脸的像素（肤色、眼睛、嘴）和新画的眼睛，头发、身体保留待机第 0 帧。动作里用 `"sheet":"face","part":"head"` 引用。
- **道具层**：动作的 `props` 时间线叠加道具。`glyphs` 是程序按字符画画的小符号（Z、"！"），带深色描边；`props` 是 GPT 画的道具，`source/props.png` + `source/props-layout.json` 经 `--derive` 打包成 `props.png`，自动登记。引用了还没画的道具时自动跳过。
- **新字段**：姿势的 `head` / `body`（整屏幕像素偏移，点头、弹跳）；动作的 `motion`（呼吸、晃腿）、`stillAt`（减弱动画时的静止时刻）、`extra`（只给闲置张望、悬挂：刚输入时不插播，输入时收回）。
- **未完成状态**改为播放会动的待机，不再冻住；工作状态和醒来不会因为刚按过键而被跳过。
- 完整方案、每个状态的做法、给 GPT 的提示词和接入步骤：工作区「鲸鱼娘全部图片-20261005/鲸鱼娘新状态方案.md」。

0.5.0 在云端用 Chromium 渲染检查过睡觉、醒来，并用替代图测试了表情抠脸与道具打包流程；`verify/mascot.mjs` 10 项全部通过（含对照本机皮肤的第一项）。改动前的备份在「_备份与存档/鲸鱼娘表情道具层前-20261005」。

## 0.6.0 思考、正面打字和电脑取放

思考沿用待机身体，只提取新原画中的脸，右上方播放点点和灯泡。打字使用 `source/typing-front.png` 的完整新人物；第 2 帧原来的托电脑动作不自然，补画 `typing-front-lift.png` 后对齐头部，只替换手臂和电脑区域。来源和完整提示词记录在 `source/front-typing-prompts-20261005.json`。侧面电脑版本未接入，存入工作区交付目录的「未采用-侧面电脑」。

`source/typing-layout.json` 指定格子、统一缩放、修正版区域和稳定区域。循环 8–11 帧共享本套新画的头发、身体、电脑和尾巴，仅替换双手及眼睛／嘴；不用旧待机身体拼打字。第 0 帧的闭合电脑从 `[13,100,30,9]` 裁成 `laptop-resting-crop.png`，用作待机道具，确保拿起前后是同一外形。`props-layout.json` 支持每件道具单独指定源文件和高度。

`manifest.restingLaptop` 保持电脑在输入框边缘固定位置。`transitions.typing` 指向 900 毫秒的 `typing-transition`：待机 → 伸手 → 托起 → 放到膝上 → 掀盖 → 敲键。回到思考／待机时倒放，电脑最终放回原处；动作中途改变目标仅改变方向和目的地，不重置进度。紧急反应可立即中断；减弱动画直接显示目标状态的静态姿势。

身体关键点锁在输入框上沿，打字图集以固定 `renderScale: 1.04` 校准新旧头部大小。相邻姿势用 55–80 毫秒的短混合平滑衔接；在透明中间画布累加颜色，避免人物在交叠时变暗。这里的混合仅用于新打字动作，不重新引入旧攀爬的网格拉伸。

交互预览 `preview/work-states.html` 使用插件同一份素材与渲染器。12/12 吉祥物自检通过；本机 Chrome 渲染 451 帧，验证打开、收起、快速反向、最新目标落地、深色和减弱动画，反向瞬间的画面逐像素相同。浏览器报告 `preview/work-states-render-check.json`，动图 `preview/思考打字与过渡.gif`。修改前备份为工作区「_备份与存档/鲸鱼娘思考打字前-20261005」。
